# Product Context: Pokemon GO Fest Event Tracker

## Problem Statement
During Pokemon GO Fest events, players need to track which shiny Pokemon they've caught across multiple rotating habitats with specific time windows. The current challenge is:

- **Memory overload**: Remembering which shinies you've already caught across 40 different Pokemon
- **Time pressure**: Each habitat only lasts 1 hour with specific rotation times
- **Manual tracking**: No in-game tool to track personal shiny progress during events
- **Optimization**: Players want to focus on Pokemon they haven't caught yet

## Target User
Pokemon GO players participating in GO Fest events who want to:
- Maximize their shiny hunting efficiency
- Track progress across multiple habitat rotations
- Avoid wasting time on Pokemon they've already caught as shinies
- Have a quick reference during the fast-paced event

## User Experience Goals

### Setup Phase (Pre-Event)
- **Quick Selection**: Rapidly choose which Pokemon to track from each habitat
- **Visual Clarity**: Clear categorization by habitat with distinct visual themes
- **Flexibility**: Easy to modify selections before the event starts

### Active Tracking (During Event)
- **One-Tap Updates**: Instant increment when a shiny is caught
- **Current Context**: Clear indication of which habitat is currently active
- **Progress Overview**: Quick visual summary of tracking progress
- **Mobile Optimized**: Thumb-friendly interface for one-handed use

### Key User Flows

1. **Initial Setup**
   - View habitat schedules and Pokemon lists
   - Select Pokemon to track (can select all, some, or none per habitat)
   - Confirm selections and proceed to tracking mode

2. **Active Tracking**
   - See current active habitat based on time
   - View selected Pokemon for current habitat
   - Tap to increment shiny count when caught
   - Quick view of overall progress

3. **Progress Review**
   - See summary of all tracked Pokemon and counts
   - Identify which Pokemon still need to be caught
   - Reset counts for future events if needed

## Success Metrics
- **Speed**: Setup completed in under 2 minutes
- **Accuracy**: Zero missed shiny tracking due to interface confusion
- **Efficiency**: Reduced time spent checking what's already been caught
- **Satisfaction**: Players feel more organized and successful during the event

## Design Principles
- **Mobile First**: Designed for phone use during outdoor gameplay
- **High Contrast**: Readable in bright sunlight conditions
- **Minimal Taps**: Reduce interaction complexity during gameplay
- **Offline Ready**: Works without internet connection during the event
